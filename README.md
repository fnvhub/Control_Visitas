## Publicación de pruebas
Rama: `Control_Visitas_MVP` · GitHub Pages · raíz `/`.

## Novedades v1.0.1
- Corrige el falso atraso de miles de días: un cliente sin historial aparece como **Sin visita registrada**.
- Versión profesional `1.0.1` visible en la interfaz y registrada en `version.json`.
- Mantiene el plan orientativo de 23 visitas semanales (5 de lunes a jueves, máximo 3 el viernes).
- Conserva las visitas ya colocadas al generar propuestas.
- La importación conserva visitas y campos manuales.

## Precaución
Antes de importar el maestro real, descarga una copia completa. Los datos permanecen en el almacenamiento local de cada dispositivo. La planificación agrupa por zona registrada, pero todavía no calcula rutas reales por carretera ni tiempos de desplazamiento.
